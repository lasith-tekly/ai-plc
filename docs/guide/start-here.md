## Before you begin

- A project folder you can use for a test, and one of the supported tools: Kiro, Claude Code, Codex or GitHub Copilot. Kiro is the most tested. See [Install](install.md).
- A small idea to try. It can be a dummy idea. Use a real one once you have seen how a run goes.
- No coding needed. You will read documents and reply in chat.

## What a run feels like

1. You type one command with your idea. The command depends on your tool: see [Install](install.md).
2. The assistant asks a few short questions, then shows a plan and waits for you to say go.
3. It drafts a deliverable. You read it, check the sources and approve it or ask for changes.
4. At each decision point it prepares a short pack. You decide: approve, rework, pivot or stop.
5. You can stop any time. Next time, run the command again and it carries on.
