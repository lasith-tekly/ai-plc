# Glossary

**Adapter**: the way `--full` turns an Outcome Pack into delivery material: `scrum`, `ai-dlc` or `plain-markdown`.

**Checkpoint**: a product decision after phase 1 or 3.

**Dry run**: a file showing exactly what would be created in a connected tool. Nothing is written until you approve it.

**Gate**: a portfolio decision after phase 2 or 4, taken on a business case.

**Known issue**: a finding on an approved file that was accepted rather than fixed. It is listed in the pack.

**MCP**: the standard way an AI tool connects to other tools such as Jira. See [Connectors](../MCP-SETUP.md).

**Outcome Pack**: one file per outcome plus an index, dependency map and roadmap, issued after Gate 2.

**PM**: you. The person who reviews and approves.

**Profile**: the YAML file that lists phases, deliverables, dependencies and decisions.

**Snapshot**: a saved copy of something read from a connected source, kept in `/product/inputs/`.

**Stale**: a deliverable that depended on something revised or sent back, so it needs checking or redoing.

**SYNTHETIC**: a label on placeholder numbers that are not real evidence.
