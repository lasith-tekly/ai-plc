# Install in Codex

## Way 1: one command

Open a terminal in your project folder and follow [Install with one command](install-one-command.md), using `codex`. This copies a `.codex` folder and an `.agents` folder into the project.

## Way 2: manual

Download, unzip and copy both the `.codex` and the `.agents` folders. See [Manual install](install-manual.md).

## Check that it loaded

Close and reopen the project in Codex. If the files still do not show, quit Codex completely and open it again. Then start with:

```
$ai-plc --ideation "<your idea>"
```

The assistant should reply by explaining what it will do and asking which mode you want. If nothing appears, see [Troubleshooting](troubleshooting.md).

Go to [Choose a run mode](run-modes.md).
